# PROJECT.md

# Project Name

ToolNest (Temporary Name)

---

# Project Overview

This project is a modern online tools website built entirely with HTML, CSS, and Vanilla JavaScript.

All tools work directly inside the browser without requiring a backend.

The website should feel like a premium product rather than a collection of random utilities.

The primary goal is to create a fast, beautiful, user-friendly, and SEO-friendly website that users enjoy returning to.

---

# Core Goals

* Fast loading
* Mobile-first
* Easy to use for every age group
* Clean and modern interface
* Excellent user experience
* SEO-friendly structure
* Accessibility support
* Consistent design across all pages
* Browser-based tools
* No login required

---

# Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript

No frameworks.

No backend.

No external UI libraries unless absolutely necessary.

---

# Website Categories

* PDF Tools
* Image Tools
* Text Tools
* Developer Tools
* SEO Tools
* Calculators

---

# Design Philosophy

The interface should be:

* Clean
* Modern
* Minimal
* Premium
* Easy to understand
* Comfortable on desktop, tablet, and mobile

Avoid clutter.

Every action should be obvious.

Users should be able to use any tool within a few seconds.

---

# User Experience Rules

Every tool should provide:

* Instant results
* Drag & Drop (where applicable)
* Copy button
* Download button
* Reset button
* Mobile-friendly layout
* Responsive design
* Smooth animations
* Dark mode compatibility
* Accessible controls
* Clear success/error messages

Navigation should always be simple.

---

# Homepage

The homepage should include:

* Hero section
* Search bar
* Popular tools
* Categories
* Featured tools
* Why choose us
* FAQ
* Footer

---

# Tool Page Structure

Every tool page should follow the same structure:

1. Hero
2. Tool Interface
3. Short Introduction
4. How It Works
5. Benefits

7. Related Tools
8. Footer

---

# SEO Rules

Every page should include:

* Unique Title
* Meta Description
* Semantic HTML
* Proper Heading Structure
* Internal Linking
* FAQ Section
* Related Tools
* Human-friendly content
* Fast loading

Never copy descriptions from other websites.

Write original content.

---

# Performance

Keep the website lightweight.

Use semantic HTML.

Write clean CSS.

Write modular JavaScript.

Avoid unnecessary animations or large libraries.

Optimize for speed.

---

# Accessibility

Support:

* Keyboard navigation
* Visible focus states
* ARIA labels where needed
* Readable typography
* High contrast
* Responsive layouts
